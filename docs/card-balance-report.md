# Relatório inicial de balanceamento

Simulação executada: 1.000 partidas reproduzíveis entre os baralhos iniciais com IA heurística.

| Resultado | Quantidade |
|---|---:|
| Vitórias do jogador | 279 |
| Vitórias da IA | 550 |
| Empates | 171 |
| Média de turnos | 55,76 |

Esta amostra não é uma conclusão definitiva de balanceamento: a IA e o modo de simulação introduzem viés. O número alto de empates e a duração média justificam investigação P2 de condições de impasse e decisões da IA. Nenhuma alteração de atributos foi feita com base apenas nesta amostra.
