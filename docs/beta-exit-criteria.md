# Critérios de saída do Beta

Nenhum P0 conhecido; P1 mitigado; partidas concluídas sem divergência; salvamentos íntegros; telemetria com consentimento; feedback acionável; amostra humana suficiente; segurança revisada em staging; build reproduzível. Sem ambiente remoto, o projeto permanece `PRONTO COM RESTRIÇÕES`.
