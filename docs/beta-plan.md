# Plano de Beta fechado

Esta entrega prepara contratos locais para convites, telemetria opcional, feedback, diagnóstico e feature flags. O acesso real deve ser validado por Auth/backend; o frontend não pode ser a autoridade.

Fases: validação local → staging isolado → convite limitado → análise de erros e compreensão → correções → expansão gradual. Nenhum convite ou deploy é enviado automaticamente.
