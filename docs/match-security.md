# Segurança de partida

O cliente envia intenção, nunca vida, dano, cristais ou resultado. `Authority` valida participação, fase, turno, custo, carta, alvo, versão e estado final. `getPlayerView` envia a própria mão, mas substitui a mão adversária por `HIDDEN_CARD` e nunca envia a ordem dos baralhos. A migration Supabase ainda é preparatória e não deve ser usada sem políticas RLS específicas.
