# Arena Draft

`createDraftSession(seed)` cria 16 rodadas com três opções. As oito primeiras são monstros e as oito últimas são itens, garantindo uma composição 8/8 quando uma opção de cada rodada é escolhida. O estado pode ser serializado no navegador para retomar a seleção.

A seleção atual é local; a série de partidas Draft e matchmaking específico ainda não estão ativados.
